Web制作の基礎をゼロから学ぶ ── HTMLとCSSで最初のページを作ってみよう

公開日: 2026年2月25日

「プログラミングを学びたいけど、何から始めればいいかわからない」。これは、Zabutonに相談にいらっしゃる方からよく聞く言葉です。その答えはシンプルです。まず、Webページがどういう仕組みでできているかを知ることから始めましょう。

あなたが今見ているこのページも、HTMLとCSSという2つのシンプルな言語で作られています。難しいアルゴリズムも、複雑な数式も必要ありません。テキストファイルを書くだけで、ブラウザに表示されるページが作れます。それがWeb制作の入口です。

HTMLって何？ ── ページの「骨格」を作る言語

HTMLは「HyperText Markup Language」の略で、Webページの構造を定義するための言語です。「見出し」「段落」「リスト」「画像」「リンク」といった要素を、タグと呼ばれる記号で囲むことで表現します。

たとえば、大きな見出しを表示したい場合は<h1>見出しテキスト</h1>と書きます。段落なら<p>本文テキスト</p>です。タグには「開始タグ」と「終了タグ」があり、その間にコンテンツを挟む。これだけが基本ルールです。

HTMLを建物に例えると「骨格・構造」に当たります。壁の位置、部屋の区切り、どこにドアがあるか。そういった設計図のような役割を果たしています。

CSSって何？ ── ページの「見た目」を整える言語

HTML だけで作ったページは、味気ないテキストと画像が並ぶだけです。そこにデザインを加えるのがCSS（Cascading Style Sheets）の役割です。文字の色・サイズ・フォント、背景色、余白、配置──すべてCSSで制御します。

HTMLが骨格なら、CSSは「内装・インテリア」です。同じ骨格（HTML）でも、CSSを変えるだけでまったく印象の異なるページになります。これがWebデザインの面白いところでもあります。

CSSの書き方は「セレクタ { プロパティ: 値; }」という形式が基本です。たとえば、ページ内のすべての段落（pタグ）の文字色を濃いグレーにしたければ、p { color: #333333; }と書きます。

最初のページを作るための3ステップ

理屈よりも、実際に手を動かすことが一番の近道です。最初のページを作るステップをまとめます。

  1. テキストエディタを用意する：Windows なら「メモ帳」、Mac なら「テキストエディット」で始められます。慣れてきたら「Visual Studio Code（VS Code）」という無料の専用エディタへ移行すると便利です。
  2. HTMLファイルを作成する：新しいファイルを作り、拡張子を「.html」として保存します。次に、基本的な構造（DOCTYPE宣言・html・head・body タグ）を書き、body の中に見出しや段落を追加してみましょう。
  3. ブラウザで確認する：保存した .html ファイルをブラウザにドラッグ&ドロップするだけで表示されます。コードを書いて保存し、ブラウザで確認する。この繰り返しが学習の基本サイクルです。

最初につまずきやすいポイント

初学者がよくつまずく場面の一つが「タグの閉じ忘れ」です。開始タグを書いたら必ず終了タグを書く習慣をつけましょう。また、日本語のファイル名を使うと文字化けの原因になることがあるため、ファイル名は英数字のみにしておくと安心です。

エラーが起きても焦る必要はありません。ブラウザは多少のミスがあっても表示しようとしてくれます。うまく表示されないときは、コードを少しずつ見直して原因を探す──この「試行錯誤」そのものがプログラミングの学び方です。

Zabutonの学習環境について

ZabutonのプログラミングカリキュラムはHTML・CSSの基礎から始まり、段階的にJavaScriptやWeb制作ツールへと学びを広げていく構成になっています。「パソコンの基本操作から学びたい」という方向けのカリキュラムもあります（適性・可否は所属予定の就労支援施設との相談で個別に判断します）。

学習はオンライン・オフラインの両方に対応しており、自分のペースで進めることができます。わからないことはすぐに質問できる環境があり、一人で悩んで止まることなく前に進める仕組みを整えています。「最初のページが表示できた！」という体験の積み重ねが、学習を続ける力につながります。

HTMLとCSSを学ぶことは、単にWebページを作るスキルを身につけるだけではありません。「自分が書いたコードが形になる」という体験は、達成感と自己効力感を育てます。その感覚が、次のステップへ進む原動力になります。ぜひ、まずは一行のコードから始めてみてください。
