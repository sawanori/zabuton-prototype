SERVICE / LEARNING

プログラミング学習

基礎から、あなたのペースでITスキルを身につける。Zabutonは一人ひとりに寄り添った学習サポートで、「できた」の積み重ねを応援します。

OVERVIEW

サービス概要

Zabutonのプログラミング学習は、IT/DXスキルの習得を通じて障がいのある方の「働く選択肢」を広げることを目的としています。就労支援施設と連携し、Web開発・データ管理・ECサイト構築など実務に直結するカリキュラムを、オンライン・オフライン両対応で学びの機会として提供します。AIエージェントを活用したITエンジニア育成支援にも対応しており、最新の技術トレンドにも対応しています。

  • プログラミング未経験・パソコン操作の基礎から学べる
  • Web開発・データ管理・ECサイト構築など実務に直結する内容
  • オンライン・オフラインを柔軟に組み合わせて受講可能
  • AIエージェントを活用したITエンジニア育成にも対応
FEATURES

Zabutonの学習サポートの特徴

基礎からステップアップ

「パソコンがよくわからない」という段階から学べるカリキュラムもあります（適性・可否は所属予定施設との相談で個別に判断）。基本操作→タイピング→プログラミングの基礎へ、一つひとつ着実にステップアップできる設計です。

個別ペースでの学習

「みんなと同じペースで進まなければ」というプレッシャーは不要。あなたの体調・集中力・生活リズムに合わせたスケジュールで学習を進めます。

オンライン・オフライン対応

横浜・みなとみらいの拠点への通所と、ビデオ通話を使ったオンラインセッションの両方に対応。通いやすい方法を自由に選べます。いずれも就労支援施設と連携した枠組みの中で、オンラインなら全国からご参加いただけます。

実務志向のカリキュラム

「就職後に使える」スキルを重視。Web開発・データ入力・EC運営など、企業が求めるIT実務に直結した内容を、技術コーチが丁寧に指導します。

チームを組んで開発する

ひとりで教材を進めるだけでなく、チームを組んで実際の開発に取り組みます。アジャイル／スクラムという短いサイクルの進め方で、現場の技術者と同じチームのなかで手を動かします。

TARGET

こんな方が対象です

  • 就労継続支援事業所（A型・B型）に所属している、または所属を予定している障がいのある方（身体・精神・知的・発達障がいなど）
  • IT/プログラミングを学びたいが、どこから始めればいいか迷っている方
  • プログラミング・パソコン操作の基礎から学びたい方
  • 自分のペースで、在宅や通所を組み合わせて学びたい方
  • まだ事業所に所属しておらず、所属も含めてこれから相談したい方
  • AIエージェントなど最新技術を活用したキャリアに興味のある方
FLOW

学びの流れ

最初の相談から就職準備へ。一人ひとりに合わせた学習プランで、着実に前進します。

01

無料相談・ヒアリング

「何から始めればいいかわからない」でも大丈夫。現在の状況・興味・目標を丁寧にヒアリングし、所属（予定）の就労支援施設と相談しながら、あなたに合ったスタートを一緒に考えます。プレッシャーなし。

→
02

個別学習計画の作成

ヒアリング内容をもとに、あなた専用の学習ロードマップを作成。ペース・ツール・オンライン/通所の割合など、生活スタイルに合わせてカスタマイズします。

→
03

学習スタート・継続サポート

計画に沿って学習を開始。定期的なセッションで技術コーチが疑問・つまずきをその場で解消します。体調変化があれば無理なく調整できる柔軟な体制です。

→
04

就職準備フェーズへ

習得したスキルをポートフォリオに整理し、就活準備・サポートフェーズへ移行。社会福祉士と連携し、スキルと強みを活かした就職活動へとつなぎます。
