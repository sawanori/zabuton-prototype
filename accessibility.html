ACCESSIBILITY

アクセシビリティ方針

株式会社Zabutonは、障害のある方を含むすべての利用者が快適にウェブサイトをご利用いただけるよう、アクセシビリティの継続的な改善に取り組んでいます。

最終更新日: （公開前に確定）

基本方針

株式会社Zabuton（以下「当社」）は、IT×福祉の橋渡しを事業の中心に据え、 障害のある方の自分らしい働く未来の実現を支援しています。 このミッションと一貫して、当社のウェブサイトは利用者の障害の有無や 使用環境に関わらず、すべての方が平等に情報にアクセスできることを目指します。

アクセシビリティへの取り組みは法令対応にとどまらず、 当社の事業の本質として継続的に改善していきます。

目標とする適合レベル

当社は、W3C（World Wide Web Consortium）が策定した ウェブアクセシビリティの国際規格である WCAG 2.1（Web Content Accessibility Guidelines 2.1）の 適合レベル AA 準拠を目指します。

現時点では完全な準拠を保証するものではありません。 継続的な改善の中で達成水準を高めていきます。 問題を発見された場合はフィードバック窓口までご連絡ください。

主な取り組み

キーボード操作への対応

マウスを使用しない場合でも、キーボードのみで当サイトのすべての機能を操作できるよう設計しています。 Tab キー・Shift+Tab キー・Enter キー・Space キー・矢印キーによる操作に対応します。 また、ページ上部に「メインコンテンツへスキップ」リンクを設置し、 繰り返しのナビゲーション読み上げを省略できます。

色のコントラスト

本文テキストと背景の色のコントラスト比は WCAG 2.1 AA 基準（4.5:1 以上）を満たすよう設計しています。 ボタン・アイコン等の UI コンポーネントは 3:1 以上を確保します。 色だけで情報を伝えることはせず、テキスト・アイコン・形状を併用します。

代替テキストの提供

情報を伝える画像にはすべて適切な代替テキスト（alt 属性）を付与します。 装飾のみを目的とする画像は、スクリーンリーダーが読み上げないよう 空の alt 属性（alt=""）を設定します。

見出し構造

各ページに H1 は 1 つのみ設置し、H2 → H3 → H4 の順で階層的に見出しを構造化しています。 スクリーンリーダーのユーザーが見出しナビゲーションでページ内を効率よく移動できます。

フォームのアクセシビリティ

お問い合わせフォームを含むすべてのフォームコントロールには、 ラベルを明示的に関連付けます。 エラーが発生した場合は内容と修正方法をわかりやすく提示します。 必須項目はテキストと属性の両方で明示します。

動きの抑制（prefers-reduced-motion）

OS やブラウザの「動きを減らす」設定（prefers-reduced-motion: reduce）を 有効にしている場合、当サイトのアニメーションおよびトランジション効果を 自動的に最小化または無効化します。 前庭障害・てんかん等の利用者が安全にサイトをご利用いただけるよう配慮しています。

フォーカスの可視化

キーボードやタッチ操作でフォーカスが当たった要素は、視覚的に識別できるフォーカスインジケータを表示します。 フォーカスリングは十分なコントラスト比（3:1 以上）を持つデザインを適用しています。

文字サイズと可読性

本文の文字サイズは 16px 以上を基準とし、行間は 1.9 以上を確保しています。 ブラウザの文字サイズ設定を変更しても、コンテンツが適切に表示されるよう設計しています。

対象範囲

本方針は、当社が運営する以下のドメインのウェブサイトを対象とします。

  • https://zabuton.co.jp/ （当社公式ウェブサイト）

外部サービス（お問い合わせシステム・アクセス解析サービス等の埋め込みコンテンツ）については、 各サービス提供者のアクセシビリティ方針に委ねます。

既知の制限事項

当サイトのアクセシビリティ監査は継続的に実施しています。 現時点での既知の制限事項については、フィードバック窓口よりお問い合わせください。 確認された問題は優先度に応じて順次改善します。
